# atmq

ATMQ - Artem Tsitronov's "Motivational" quotes.
A bookmarklet that display a little box in the top-right corner, with a roasting sentence.
I mean, it motivates you. But it also makes your self-esteem go down.
Made for (HackClub)[https://hackclub.com]

## /* *Usage* */

Clone the repository, open the `index.html` file, and drag the link in the webpage to the bookmarks.
To display a quote, just open the bookmark.
